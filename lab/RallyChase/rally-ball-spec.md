# ラリーボール(仮題) デモ版 指示書

## 1. コンセプト

2D見下ろし型の車ゲーム。高速で走る車の慣性をコントロールし、一直線に飛んでいくボールをひたすら追いかける。

- 楽しさの核:高速走行のスピード感、ドリフトで慣性を制御する難しさと気持ちよさ、障害物を破壊する爽快感
- 「速いほど壊せる、速いほど曲がれない」というスピードと制御のトレードオフが軸
- 勝利条件はなし。ボールを取るとスコアが上がっていくだけ
- 今回は「走ってボールを追うだけで楽しい」ことを確かめるデモ

## 2. 技術構成

- **JavaScript + HTML5 Canvas**。ブラウザで `index.html` を開けば動くこと
- **物理ライブラリは使わない**。車・ボール・地形の物理はすべて自作の簡易物理で書く
  - 理由:高さ(Z軸)を扱う必要がある。ボールは物理的でないルールで動く。車の操作感を調整しやすくしたい
- 座標は X, Y(平面) + Z(高さ)の2.5D
- 最初は1ファイル、または少数のJSファイル(ES modules)で構成。ビルドツールは不要
- 外部ライブラリは原則なし(調整パネル用の lil-gui をCDNから読み込むのはOK)
- 地形生成用のノイズ関数(value noise または simplex noise)は自前で実装する
- 乱数はシード付きにし、チャンク座標から決定的に生成できるようにする

## 3. 操作

| 入力 | 動作 |
|---|---|
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Space | サイドブレーキ(横グリップが大きく下がり、ドリフトする) |
| R | リスタート(スコア0、車とボールを初期化) |
| F1 または ` | 調整パネルの表示切り替え |

ゲームパッド対応は後回しでよい。

## 4. フィールド(無限生成)

- ワールドは無限。**チャンク方式**(例:1チャンク 512×512px)で生成する
- カメラ周辺のチャンクだけ生成・保持し、遠くなったチャンクは破棄する
- 同じチャンク座標からは常に同じ地形・障害物が生成される(シード付き乱数)
- 破壊済みの障害物はIDで記録し、チャンクを再生成しても復活しないようにする

### 4.1 地形(ハイトマップ)

- 地形は関数 `height(x, y)` で定義する。どこでも高さを取得できること
- 傾きは `gradient(x, y)`(差分で計算)で取得し、車とボールの両方が同じ関数を使う
- 地形の構成要素:
  - **平地**:大部分は平坦にする。走りやすさが基本
  - **丘**:丸い盛り上がり。越えると跳躍する
  - **傾いた丘・斜面**:一方向に傾いたもの。車は横滑りし、ボールはバウンド時に向きが変わる
  - **段差・ジャンプ台**:急に高さが変わる箇所。大きく跳躍する
- 起伏の量はパラメータで調整できるようにする

### 4.2 地面の描画

- 高さと傾きに応じて陰影をつける(ヒルシェード。光源方向を固定して明暗を計算)
- チャンクごとにオフスクリーンcanvasへ描画してキャッシュする
- **スピード感のため、地面の細かい模様を多めに散らす**(草、小石、ひび、色ムラなど)
  - 見下ろし視点のスピード感は、地面の模様が流れる速さで決まる。最重要
- 丘の縁や斜面がひと目で分かる見た目にする

### 4.3 障害物

チャンク生成時にランダム配置する。互いの最小間隔を守り、ゲーム開始地点の周辺には置かない。

- **壊せない障害物**:大きめ(半径80〜200px程度)。岩、建物など
  - 大きく回り込むカーブを強制する役割
  - 形は円または矩形に限定し、判定を単純にする
- **壊せる障害物**:小〜中サイズ。木箱、柵、小屋など
  - 車の速度が閾値(例:最高速の60%)以上で接触すると破壊される
  - 破壊時に破片パーティクルを出し、車は少しだけ減速、画面も少し揺らす
  - 閾値未満で接触したら、壊せない障害物と同じく弾かれる
- 障害物には高さがある。車のZが障害物の高さを上回っていれば、上を飛び越えられる

## 5. 車

### 5.1 状態

位置 (x, y, z)、速度 (vx, vy, vz)、向き (angle)、角速度、接地フラグ。

### 5.2 接地中の挙動(アーケード型の自作モデル)

- 速度を車の向きに対して「前後成分」と「横成分」に分解し、それぞれ別の摩擦をかける
  - 横摩擦が強ければグリップ、弱ければドリフト
  - サイドブレーキ中は横摩擦を大きく下げる
- アクセルで前方向に加速。最高速あり
- ハンドルの効きは速度に応じて変える(停止中は回らず、超高速では効きが落ちる)
- 斜面では、地形の傾きに沿って下方向へ力がかかる(傾いた丘で横滑りする)
- 接地中は z = height(x, y) に追従する

### 5.3 跳躍と空中

- 接地中は、地形の傾きと水平速度から上下方向の速度を求める(vz = 水平速度と勾配の内積)
- 丘の頂上や段差で、地形が車より速く下がった場合は離陸する(z が地形より上になったら空中)
- 空中では重力がかかる。**アクセル・ハンドルは効かない**(慣性のまま飛ぶ)
- 着地時:
  - 落下速度が大きいと少しバウンドする(反発係数)
  - 着地の瞬間に車の見た目を一瞬つぶす(スカッシュ)
  - 土煙と画面揺れを出す
  - 着地直後の短い時間はグリップを下げてもよい(調整値)

### 5.4 衝突

- 壊せない障害物:めり込みを押し戻し、法線方向の速度を減衰付きで反射させる。画面揺れ
- 壊せる障害物:4.3の通り

## 6. ボール

ボールは物理シミュレーションではなく、**決まったルールで動く物体**。

- **水平速度は常に一定**。止まらない、減速しない(車の最高速より遅く設定し、追いつけるようにする。例:最高速の65%)
- 水平方向は基本的に一直線に飛ぶ
- 縦方向は重力付きで放物線を描き、地面(height(x, y))に触れるとバウンドする
  - バウンドの高さは毎回ほぼ一定(減衰しない)。バウンドは「高さの表現」と「向きの変化」のため
- **バウンドした瞬間だけ**、その地点の地形の傾きに応じて進行方向を少し曲げる
  - 1回のバウンドで曲がる角度には上限を設ける(例:最大10度)
  - 曲げたあと、水平速度を一定値に正規化する
  - 空中では一切曲がらない
- **障害物は無視して通過する**。描画は常に障害物より上のレイヤー
  - 障害物の上を通るとき、影は障害物の上に落ちているように見せる

### 6.1 捕獲と再射出

- 車とボールの水平距離が一定以内、かつ高さの差が一定以内なら捕獲。スコア+1
- 捕獲した地点から、**ランダムな方向**(360度)に新しいボールを射出する
  - 射出直後は高めの放物線で打ち上げる
- 捕獲時に小さな演出(フラッシュ、パーティクル、スコアのポップ)

### 6.2 ボールの位置の表示

- ボールが画面外にあるときは、画面端にボールの方向を示す矢印と距離を表示する

## 7. カメラ

- 車を追従する。追従はなめらかに(lerp)
- **先読み**:車の速度方向に、速度に比例してカメラを先へずらす。高速ほど先が見える
- **ズーム**:速度に応じてズームアウトする(低速 1.0 から高速 0.7 程度)
- 画面揺れ:着地、衝突、破壊時。強さは調整できるようにする

## 8. 高さの表現(見下ろし2.5D)

デモで最も確認したい部分。

- **影と本体を分けて描く**:影は地面の位置 (x, y) に描き、本体は z に比例して画面上方向にずらして描く
- **本体の拡大**:z に応じて拡大する(地上 1.0 から最大 1.3 倍程度)
- **影の変化**:z が高いほど小さく、薄く
- 車もボールも同じルールで描く
- 描画順:地面 → タイヤ痕 → 影 → 障害物 → 車 → ボールの影 → ボール → エフェクト → UI
  - 空中の車が障害物を越えるときは、障害物より手前に描く

## 9. エフェクト

- タイヤ痕:横滑りが大きいとき(ドリフト中)に地面へ残す。古いものは消えていく
- 土煙:ドリフト中、着地時
- 高速時の残像またはスピードライン
- 破片:障害物破壊時
- 演出は最初は控えめでよい。まず操作感を優先する

## 10. UI

- スコア
- 速度(メーターまたは数値)
- 画面外のボールへの矢印と距離
- 調整パネル(後述)

## 11. 調整パネル(重要)

操作感はAIでも一発では決まらないので、**主要なパラメータをすべて実行中に変更できるようにする**。lil-gui 推奨。値はlocalStorageに保存し、「デフォルトに戻す」ボタンも付ける。

最低限、以下を調整可能にする(初期値は目安):

- 車:加速、最高速、ハンドルの効き、前後摩擦、横摩擦、サイドブレーキ時の横摩擦、斜面の横滑りの強さ、重力、着地時の反発
- 破壊:破壊できる速度の閾値、破壊時の減速量
- ボール:水平速度、バウンドの高さ、バウンド時の最大曲がり角度、捕獲判定の距離
- 地形:起伏の量、丘・斜面・段差の出現頻度
- 障害物:密度、壊せる/壊せないの比率、サイズ範囲
- カメラ:先読み量、追従のなめらかさ、ズーム範囲、画面揺れの強さ
- 高さ表現:Zあたりの描画オフセット量、拡大率
- デバッグ表示:当たり判定、地形の勾配ベクトル、チャンク境界の表示切り替え

## 12. 実装の順番

各段階で、ブラウザで動作確認できる状態にしてから次へ進むこと。

1. **平らな地面で車を走らせる**:車の物理、ドリフト、カメラ(先読み・ズーム)、調整パネル。地面の模様でスピード感を確認。**ここで走るだけで楽しくなるまで調整する**
2. **無限生成の地面**:チャンク方式の生成と破棄、地面の模様
3. **ボールとスコア**:直線飛行、一定速度、捕獲と再射出、画面外の矢印(この段階では平地でバウンドだけ)
4. **障害物**:壊せない・壊せるの配置、衝突、破壊
5. **地形の高さ**:ハイトマップ、陰影、車の跳躍・着地、斜面の横滑り、ボールのバウンドでの向きの変化、高さ表現の描画
6. **エフェクトの追加**:タイヤ痕、土煙、残像、破片、画面揺れ
